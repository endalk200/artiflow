# Share an Effect HTTP API Contract Between Web and CLI

`packages/api-contract` owns the transport-only `ArtiflowApi` declaration, endpoint groups, and request, response, and error schemas using the installed Effect HTTP API modules, while `apps/web` owns `HttpApiBuilder` handlers and the Next.js web-handler adapter and `apps/cli` owns `HttpApiClient`, Node HTTP transport, presentation, and exit-code mapping. Effect HTTP API handlers and server-rendered pages both call the same app-owned Project and Artifact services directly rather than calling one another over HTTP, and those services keep Drizzle private behind persistence operations. This prevents endpoint paths and wire schemas from drifting without coupling the contract package to persistence or either application; because the selected Effect v4 HTTP API is under `effect/unstable/*`, every participating package pins the same Effect beta version.
