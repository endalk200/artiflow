# Version the Artifact Source Format

Every Revision records a platform-managed Source Format version supplied through the publication protocol rather than embedded in frontmatter, and the platform rejects unknown versions instead of guessing how to interpret them. V1 identifies trusted Fumadocs remote MDX plus the initial Visual Component contract as Source Format 1, giving later constrained formats and rendering behavior a way to coexist with, migrate, or deliberately retire immutable historical source.
