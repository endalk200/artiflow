Welcome to the lab. Every page in this section begins as a local `.mdx` file, is compiled by **Fumadocs MDX**, and is rendered through a statically generated Next.js route.

<Callout title="What to look for">
  The sidebar, table of contents, previous/next navigation, search data, syntax highlighting, and theme switcher are all driven by Fumadocs.
</Callout>

## How the pipeline fits together

<Steps>
  <Step>
    ### Author content

    Write Markdown, JSX, and frontmatter in `content/docs`.
  </Step>
  <Step>
    ### Generate a typed source

    `fumadocs-mdx` creates the `.source` collection used by the app.
  </Step>
  <Step>
    ### Render with React

    The catch-all docs route supplies Fumadocs and custom components to the compiled MDX body.
  </Step>
</Steps>

## The smallest useful file

```mdx title="content/docs/hello.mdx"
---
title: Hello, MDX
description: A tiny page with a rich component.
---

# Markdown still works

<Callout>But this is a React component.</Callout>
```

<Callout type="info" title="Try it live">
  Edit any file under `content/docs` while `npm run dev` is running. Fumadocs watches the collection and refreshes the generated source.
</Callout>
